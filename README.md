# Najot Ta'lim — Zamonaviy Bitta Sahifali Veb-Sayt (Landing Page)

Ushbu loyiha **Najot Ta'lim** o'quv markazi misolida o'quvchilarga professional, zamonaviy va ta'sirchan landing page qanday yaratilishini ko'rsatish uchun tayyorlandi.

---

## 🚀 Loyihaning asosiy bo'limlari

1. **Header / Navbar**:
   - Vektorli Najot Ta'lim SVG logotipi;
   - Qulay navigatsiya menyusi va tezkor bog'lanish tugmasi;
   - Mobil moslashuvchanlik (burger menyu).

2. **Hero Section (Kompaniya haqida qisqa ma'lumot)**:
   - Ta'sirchan sarlavha va shior;
   - Asosiy ko'rsatkichlar (15,000+ bitiruvchilar, 85%+ ishga joylashish, 100+ mentorlar);
   - Zamonaviy floating badge'lar va sifatli vizual.

3. **Biz haqimizda (About Najot Ta'lim)**:
   - 4 ta asosiy ustun: Kuchli mentorlar, Coworking & sharoit, Karyera markazi, Real portfolio loyihalar.

4. **10 ta Zamonaviy Kurslar Katalogi**:
   - Interaktiv kategoriya filtrlari (*Barchasi*, *Sun'iy Intellekt*, *Dasturlash*, *Dizayn & Marketing*);
   - 10 ta dolzarb yo'nalish kartochkasi:
     1. AI Muhandisligi (AI Engineering)
     2. AI Avtomatlashtirish & Agentlar
     3. Frontend Dasturlash (React / Next.js)
     4. Backend Dasturlash (Go / Python)
     5. Mobile Dasturlash (Flutter)
     6. Grafik Dizayn & Brending
     7. UI/UX Dizayn
     8. Dasturlash Foundation (IT Start)
     9. Kiberxavfsizlik (Cybersecurity)
     10. Raqamli Marketing & SMM
   - Har bir kursda *"Batafsil"* (modal oyna) va *"Kursga yozilish"* (anketaga yo'naltiruvchi) funksiyasi.

5. **Bitiruvchilar Fikrlari (Social Proof & Testimonials)**:
   - Realistik o'quvchilar profillari, baholar va ularning yetakchi IT kompaniyalarga (EPAM, Uzum, IT Park) ishga kirish tajribalari.

6. **Ko'p beriladigan savollar (FAQ)**:
   - Interaktiv akkordeon (ochiluvchi-yopiluvchi bloklar).

7. **Murojaat Anketasi (Lead Generation Form)**:
   - Ism, O'zbekiston telefon raqami formati (`+998 (__) ___-__-__`), qiziqqan kursni tanlash va savol;
   - Dinamik bog'lanish (kartochkadan bosilganda tanlangan kurs avtomatik tanlanadi);
   - Muvaffaqiyatli jo'natish modali.

8. **Footer**:
   - Filiallar, ijtimoiy tarmoqlar havolalari, aloqa ma'lumotlari.

---

## 💻 Loyihani ishga tushirish

Loyiha mutlaqo mustaqil (standalone) bo'lib, uni 2 xil usulda ishga tushirish mumkin:

### 1-usul (Eng oson — darhol ochish):
Fayllar menejerida `index.html` faylini istalgan brauzerda (Chrome, Edge, Firefox) ikki marta bosib oching.

### 2-usul (Lokal server orqali):
Terminalda quyidagi buyruqlardan birini bajaring:
```bash
# Node.js orqali:
npx serve .

# yoki Python orqali:
python -m http.server 3000
```
Brauzerda `http://localhost:3000` manzilini oching.
